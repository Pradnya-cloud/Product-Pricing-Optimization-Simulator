# Data Dictionary

| Field | Meaning |
|---|---|
| Customer ID | Unique synthetic customer key |
| Customer Segment | Target customer group |
| Region | Geographic market |
| Current Price | Current monthly price anchor |
| Proposed Price | Price being simulated |
| Competitor Price | Illustrative competitor anchor |
| Unit Cost | Variable cost per customer |
| Willingness to Pay | Estimated maximum acceptable price |
| Expected Demand | Estimated visitors/opportunities |
| Number of Customers | Expected converted customers |
| Conversion Rate | Customers / demand |
| Churn Rate | Estimated monthly churn |
| Discount % | Applied discount |
| Revenue | Net price × customers |
| Gross Profit | Revenue − variable cost |
| Gross Margin % | Gross profit / revenue |
| CAC | Customer acquisition cost |
| LTV | Modeled customer lifetime value |
| LTV:CAC Ratio | LTV divided by CAC |
| Price Sensitivity Score | 0–100 modeled sensitivity |
| Pricing Scenario | Scenario classification |
| Recommended Price | Segment-level modeled recommendation |
| Final Decision | Recommend/Test flag |
